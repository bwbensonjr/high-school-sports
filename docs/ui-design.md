# Website Principles

- The site is served through GitHub pages.
- If possible, the user interface itself should be driven off of daily-regneneratd data files and not require daily regeneration of the UI itself.
- For each sport it should be possible to see:
  - Recent games with results
  - Upcoming games with predicted spreads
  - Cross-division Elo
  - Division-level Elo 
- It should be possible to view every sport, but current season sports should be emphasized, seen by default.
- The design should be simple and follow the [UI Design Guidelines](ui-design-principles.md).
